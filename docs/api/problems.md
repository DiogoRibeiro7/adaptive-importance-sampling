# Problems

Ready-made limit-state functions. [`BenchmarkProblems`][safe_ice.BenchmarkProblems]
and [`HeatTransferProblem`][safe_ice.HeatTransferProblem] reproduce the examples
of the Safe-ICE paper; the reference probabilities they are tested against are
listed in [Accuracy and benchmarks](../guide/accuracy.md#benchmark-problems).
The remaining classes build system, time-variant, random-field and network
limit states for your own experiments.
